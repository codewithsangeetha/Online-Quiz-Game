# Online Quiz Game in C

A two-team command-line quiz game developed using C programming.

## About the Project

This project allows two teams to compete by answering multiple-choice programming questions. Teams earn points based on their answers, and a tie-breaker round is played if both teams finish with equal scores.

## Features

- Two-team gameplay
- Multiple-choice questions
- Two attempts per question
- Score calculation
- Tie-breaker round
- Winner announcement

## Technologies Used

- C Programming
- Standard Input/Output (`stdio.h`)
- Standard Library (`stdlib.h`)

## How to Run

Compile the program using a C compiler:

```bash
gcc quiz_game.c -o quiz_game


Run the program on Linux/macOS:

```bash
./quiz_game
```

On Windows:

```bash
.\quiz_game.exe
```
